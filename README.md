# MediVision-AI--Intelligent-Health-Risk-Analysis-System

MediVision AI is an educational healthcare analysis application that uses Artificial Intelligence, Machine Learning, and Deep Learning to analyze basic health parameters and provide a simple risk indication.

## Features

* Random Forest based ML prediction
* Neural Network based DL prediction
* AI rule-based risk analysis
* Health parameter visualization
* Prediction history
* Interactive Streamlit interface

## Health Parameters

* Age
* Blood Pressure
* Blood Sugar
* Cholesterol
* BMI

## Tech Stack

* Python
* Streamlit
* Pandas
* Scikit-learn
* Matplotlib

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Project Workflow

```text
User Input
    ↓
Data Processing
    ↓
ML + DL Prediction
    ↓
AI Risk Analysis
    ↓
Results & Visualization
```

## Disclaimer

This is an educational mini-project and is not intended for medical diagnosis or treatment.
